### Juego de Naves en C++

Videojuego de naves espaciales desarrollado en C++ utilizando los principios de la Programación Orientada a Objetos (POO). El jugador controla una nave en la consola, esquiva asteroides y dispara para sobrevivir.

### Objetivo

Aplicar los conceptos de clases, objetos, encapsulamiento, atributos privados y métodos públicos mediante el desarrollo de un videojuego de consola.

### Controles

Tecla| Acción
"W"| Mover hacia arriba
"A"| Mover hacia la izquierda
"S"| Mover hacia abajo
"D"| Mover hacia la derecha
"ESPACIO"| Disparar

### Cómo ejecutar el juego

1. Clonar o descargar el repositorio.
2. Abrir una terminal en la carpeta del proyecto.
3. Compilar el archivo "src/main.cpp" utilizando un compilador de C++ compatible con Windows.
4. Ejecutar el programa generado.

### Documentación

La carpeta "docs/" contendrá el informe y los manuales del proyecto. Las capturas de pantalla del juego se guardarán en "capturas/".
